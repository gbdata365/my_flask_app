# 인구통계 분석 시스템 가이드

> **버전**: 1.0
> **최종 수정일**: 2026-01-12
> **작성**: ljs

---

## 1. 시스템 개요

이 시스템은 **대한민국 인구통계 데이터**를 분석하고 시각화하는 웹 애플리케이션입니다.
공공데이터포털(data.go.kr)의 인구 API 데이터를 PostgreSQL 데이터베이스에 저장하고, Flask 웹 프레임워크를 통해 대시보드와 AI 챗봇 기능을 제공합니다.

### 1.1 주요 기능

| 기능 | 설명 |
|------|------|
| **대시보드** | 연령별 인구, 1인가구 현황을 차트와 테이블로 시각화 |
| **AI 챗봇 (데이터콩)** | 자연어 질문을 SQL로 변환하여 데이터 조회 및 분석 |
| **데이터 자동 수집** | 공공데이터 API에서 월별 인구 데이터 자동 수집 |

## 2. 보유 데이터

### 2.1 데이터 출처

| API명 | 출처 | 주요 내용 |
|-------|------|----------|
| 인구 및 세대현황 | 공공데이터포털 | 읍면동별 총인구, 세대수, 남녀인구 |
| 연령대별 인구 | 공공데이터포털 | 5세 단위 연령대별 인구 |
| 1세별 인구 | 공공데이터포털 | 0세~110세 이상 1세 단위 인구 |
| 1인세대수 | 공공데이터포털 | 연령별 1인가구 현황 |

### 2.2 데이터베이스 테이블

#### 팩트(Fact) 테이블 - 실제 데이터
| 테이블명 | 설명 | 주요 컬럼 |
|---------|------|----------|
| `fact_population_basic` | 기본 인구통계 | 총인구, 남녀인구, 세대수 |
| `fact_population_by_age` | 1세별 인구 | male_age_0 ~ male_age_110_over, female_age_0 ~ female_age_110_over |
| `fact_single_household` | 1인가구 현황 | 연령별 남녀 1인가구수 |

#### 차원(Dimension) 테이블 - 코드/분류
| 테이블명 | 설명 | 주요 컬럼 |
|---------|------|----------|
| `dim_admin_area` | 행정구역 정보 | admin_code, sido_nm, sigungu_nm, emd_nm |
| `code_age_group` | 연령그룹 정의 | category, code, code_name, age_start, age_end |

#### 캐시 테이블 - 집계 데이터
| 테이블명 | 설명 | 주요 컬럼 |
|---------|------|----------|
| `cache_sigungu_indicators` | 시군구별 지표 | 고령화율, 유소년율, 1인가구비율 등 |

#### 현재 보유 데이터 기간 (2026-01-12 기준)

| 테이블명 | 보유 기간 | 개월수 | 기준년월 목록 |
|---------|----------|--------|--------------|
| `fact_population_basic` | 2025-10 ~ 2025-11 | 2개월 | 2025-10, 2025-11 |
| `fact_population_by_age` | 2024-11 ~ 2025-11 | 13개월 | 2024-11, 2024-12, 2025-01, 2025-02, 2025-03, 2025-04, 2025-05, 2025-06, 2025-07, 2025-08, 2025-09, 2025-10, 2025-11 |
| `fact_single_household` | 2024-11 ~ 2025-11 | 13개월 | 2024-11, 2024-12, 2025-01, 2025-02, 2025-03, 2025-04, 2025-05, 2025-06, 2025-07, 2025-08, 2025-09, 2025-10, 2025-11 |
| `cache_sigungu_indicators` | 2025-10 ~ 2025-11 | 2개월 | 2025-10, 2025-11 |

> **참고**:
> - 공공데이터 API는 매월 10일 이후 전월 데이터가 공개됩니다.
> - 새 데이터 수집은 `api_to_db.py --collect` 명령으로 실행합니다.
> - 캐시 테이블은 `transfer.py` 실행으로 갱신됩니다.

### 2.3 주요 지표

| 지표명 | 계산식 | 설명 |
|--------|--------|------|
| **고령화율** | 65세이상 인구 / 총인구 × 100 | 노인 인구 비율 |
| **유소년율** | 0-14세 인구 / 총인구 × 100 | 어린이·청소년 비율 |
| **생산가능인구율** | 15-64세 인구 / 총인구 × 100 | 경제활동 가능 인구 비율 |
| **노령화지수** | 65세이상 / 0-14세 × 100 | 유소년 100명당 노인 수 |
| **1인가구비율** | 1인가구 / 총세대수 × 100 | 독거 가구 비율 |
| **성비** | 남자인구 / 여자인구 × 100 | 여자 100명당 남자 수 |

### 2.4 지역 범위

- **전국**: 17개 시도
- **시도**: 서울, 부산, 대구, 인천, 광주, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주
- **시군구**: 약 250개
- **읍면동**: 약 3,500개

## 4. 대시보드1 사용법

### 4.1 개요

**대시보드1**은 연령별 인구 및 1인가구 현황을 시각적으로 분석하는 대시보드입니다.

### 4.2 주요 기능

#### 필터 옵션
| 필터 | 설명 |
|------|------|
| **기준년월** | 조회할 데이터 기준 월 선택 |
| **보기 유형** | 권역별 / 시도별 / 시군구 중 선택 |
| **시도** | 시군구 보기 시 특정 시도 선택 |
| **연령그룹** | 분석할 연령 구분 기준 선택 |

#### 연령그룹 카테고리
| 카테고리 | 구분 |
|---------|------|
| **5세 단위** | 0-4세, 5-9세, 10-14세, ... 95세 이상 |
| **10세 단위** | 0-9세, 10-19세, 20-29세, ... 90세 이상 |
| **정책지표** | 유소년(0-14), 생산가능(15-64), 고령(65+) |
| **생애주기** | 영유아, 아동, 청소년, 청년, 중년, 장년, 노년 |

### 4.3 제공 차트

| 차트 유형 | 설명 |
|----------|------|
| **인구 피라미드** | 연령별 남녀 인구 분포를 피라미드 형태로 시각화 |
| **도넛 차트** | 연령그룹별 인구/1인가구 구성비 |
| **이중 축 차트** | 인구수(막대)와 1인가구 비율(선)을 함께 표시 |
| **막대 차트** | 연령별 남녀 인구/1인가구 비교 |

### 4.4 피벗 테이블

지역별(행) × 연령그룹별(열) 데이터를 테이블로 제공합니다.

- **표시 항목 선택**: 인구수, 1인가구수, 비율(%) 중 선택
- **연령그룹 선택**: 표시할 연령그룹 다중 선택
- **정렬 기능**: 컬럼 헤더 클릭으로 오름차순/내림차순 정렬

### 4.5 사용 예시

```
1. 기준년월: 2025.11 선택
2. 보기 유형: 시군구 선택
3. 시도: 경상북도 선택
4. 연령그룹: 정책지표(유소년/생산/고령) 선택
5. [조회] 버튼 클릭

→ 경상북도 시군구별 고령화율, 유소년율 등을 차트와 테이블로 확인
```

## 5. 데이터콩 (AI 챗봇) 사용법

### 5.1 개요

**데이터콩**은 자연어로 인구통계 데이터를 질문하면 AI가 SQL을 생성하여 답변하는 챗봇입니다.

### 5.2 지원 LLM

| LLM | 설명 |
|-----|------|
| **Claude** | Anthropic Claude API (기본값) |
| **OpenAI** | OpenAI GPT API |
| **Solar** | 업스테이지 Solar API (한국어 특화) |

### 5.3 질문 유형

#### 순위/비교 질문
```
• 고령화율이 가장 높은 시군구 10개
• 경상북도에서 1인가구 비율 높은 시군
• 인구가 가장 많은 시군구 20개
• 전라남도 노인인구 많은 시군
```

#### 차트 생성 질문
```
• 경북 시군구별 고령화율 차트
• 경북 시군구별 6세이하 인구비율 그래프
• 서울 구별 1인가구 비율 시각화
```

> **TIP**: "차트", "그래프", "시각화" 키워드를 포함하면 차트가 생성됩니다.

#### 시계열 분석 질문
```
• 경북 구미시 고령화율 월별 추이
• 경북 주요 시군 인구 추이 비교
• 서울 고령화율 전월 대비 변화
• 경기도 인구 전년 동월 대비
```

#### 특정 지역 조회
```
• 수원시 인구 현황
• 포항시 고령화율
• 제주도 1인가구 현황
```

### 5.4 결과 출력

| 출력 형식 | 설명 |
|----------|------|
| **테이블** | 조회 결과를 표 형태로 표시 |
| **차트** | 막대, 라인 차트 자동 생성 |
| **인사이트** | AI가 데이터를 분석한 해석 제공 |
| **CSV 다운로드** | 결과 데이터를 CSV로 다운로드 |
| **자동 저장** | output 폴더에 결과 자동 저장 |

### 5.5 사용 예시

```
질문: "경북 시군구별 고령화율 차트"

→ AI가 SQL 생성:
   SELECT sigungu_nm, elderly_ratio
   FROM cache_sigungu_indicators
   WHERE sido_nm = '경상북도'
   ORDER BY elderly_ratio DESC

→ 결과: 막대 차트 + 데이터 테이블 + 인사이트 분석
```

### 5.6 주의사항

- 질문은 **인구통계 관련 내용**만 처리 가능합니다
- 데이터 기준월은 자동으로 최신 월이 적용됩니다
- 복잡한 질문은 단순하게 나누어 질문하면 더 정확합니다

## 6. 시작하기

### 6.1 시스템 요구사항

| 항목 | 요구사항 |
|------|---------|
| Python | 3.10 이상 |
| 데이터베이스 | PostgreSQL 13 이상 |
| 브라우저 | Chrome, Edge, Firefox (최신 버전) |

### 6.2 환경 설정

```bash
# 1. 가상환경 활성화
.venv\Scripts\activate  # Windows
source .venv/bin/activate  # Linux/Mac

# 2. 의존성 설치
uv pip install -r requirements.txt

# 3. 환경변수 설정 (.env 파일)
DB_HOST=localhost
DB_PORT=5432
DB_NAME=population_db
DB_USER=your_user
DB_PASSWORD=your_password

# LLM API 키 (데이터콩 사용 시)
ANTHROPIC_API_KEY=sk-ant-xxx
OPENAI_API_KEY=sk-xxx
SOLAR_API_KEY=xxx
```

### 6.3 실행

```bash
# Flask 서버 실행
python main_app.py

# 브라우저에서 접속
http://localhost:5000
```
