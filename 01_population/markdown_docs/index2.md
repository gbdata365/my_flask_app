## 1. 시스템 개요

**인구 집계표 대시보드**는 시도별/시군구별 인구 지표를 집계하고, 다양한 형식(Excel, Markdown, HTML)으로 내보내기할 수 있는 대시보드입니다.

### 1.1 주요 기능

| 기능 | 설명 |
|------|------|
| **지표별 집계표** | 연령별 인구 지표를 탭 형식으로 조회 |
| **다중 기준월 비교** | 여러 기준월 데이터를 한 화면에서 비교 |
| **차트 시각화** | 지표별 막대 차트 자동 생성 |
| **데이터 내보내기** | Excel, Markdown, HTML 형식으로 다운로드 |
| **정렬 기능** | 컬럼별 오름차순/내림차순 정렬 |

## 2. 화면 구성

### 2.1 조회 조건

```
┌─────────────────────────────────────────────────────────────────┐
│  기준년월: [2025-11, 2025-10 ▼]  시도: [경상북도 ▼]             │
│  연령구분: ○ 5세별  ● 10세별  ○ 정책지표  ○ 생애주기           │
│  ☑ 하위 시군구 포함                          [조회]            │
└─────────────────────────────────────────────────────────────────┘
```

| 조건 | 설명 | 기본값 |
|------|------|--------|
| **기준년월** | 조회할 데이터 기준 월 (복수 선택 가능) | 최근 2개월 |
| **시도** | 조회할 시도 선택 | 전체 (시도별 합계) |
| **연령구분** | 연령 그룹 분류 방식 | 10세별 |
| **하위 시군구 포함** | 시군구 하위 행정구역 포함 여부 | 체크 |

### 2.2 연령구분 옵션

| 구분 | 연령 그룹 |
|------|----------|
| **5세별** | 0-4세, 5-9세, 10-14세, ... 95세 이상 (20개 그룹) |
| **10세별** | 0-9세, 10-19세, 20-29세, ... 90세 이상 (10개 그룹) |
| **정책지표** | 유소년(0-14), 생산가능(15-64), 고령(65+), 전기고령(65-74), 후기고령(75+) |
| **생애주기** | 영유아, 아동, 청소년, 청년, 중년, 장년, 노년 |

│  ┌───────────────────────────────────────────────────────────┐  │

│  ├───────┼────────────────┼────────────────┼────────────────┤  │

## 3. 사용법

### 3.1 기본 조회

1. **기준년월 선택**: 드롭다운에서 비교할 월 선택 (Ctrl+클릭으로 복수 선택)
2. **시도 선택**: 특정 시도 선택 시 해당 시도의 시군구 데이터 조회
3. **연령구분 선택**: 분석 목적에 맞는 연령 그룹 선택
4. **하위 시군구 포함**: 체크 해제 시 시/군 단위로 그룹화
5. **[조회] 버튼 클릭**

### 3.2 테이블 정렬

| 조작 | 설명 |
|------|------|
| **컬럼 헤더 클릭** | 해당 컬럼 기준 정렬 (토글: 오름차순 ↔ 내림차순) |
| **정렬 아이콘** | ▲ 오름차순, ▼ 내림차순 표시 |

> **참고**: 정렬 시 '합계' 행은 항상 최상단에 고정됩니다.

### 3.3 데이터 내보내기

1. 테이블 정렬 상태 설정 (원하는 컬럼 클릭)
2. **[Excel]**, **[Markdown]**, **[HTML]** 버튼 클릭
3. 파일 자동 다운로드

| 형식 | 특징 |
|------|------|
| **Excel** | 지표별 시트 분리, 서식 적용 |
| **Markdown** | 문서 작성용, 테이블 포맷 |
| **HTML** | 탭 형식 보고서, 차트 포함 |

> **중요**: 내보내기 시 화면에서 설정한 정렬 상태가 그대로 반영됩니다.

## 4. 주요 지표 설명

### 4.1 인구 지표

| 지표명 | 한글명 | 계산식 |
|--------|--------|--------|
| `youth_pop` | 유소년인구 | 0-14세 인구 합계 |
| `working_pop` | 생산가능인구 | 15-64세 인구 합계 |
| `elderly_pop` | 노령인구 | 65세 이상 인구 합계 |
| `early_elderly_pop` | 전기고령인구 | 65-74세 인구 합계 |
| `late_elderly_pop` | 후기고령인구 | 75세 이상 인구 합계 |

### 4.2 비율 지표

| 지표명 | 한글명 | 계산식 |
|--------|--------|--------|
| `youth_ratio` | 유소년율 | 유소년인구 / 총인구 × 100 |
| `working_ratio` | 생산가능인구율 | 생산가능인구 / 총인구 × 100 |
| `elderly_ratio` | 고령화율 | 노령인구 / 총인구 × 100 |
| `aging_index` | 노령화지수 | 노령인구 / 유소년인구 × 100 |

## 5. 내보내기 모듈 (export_utils)

### 5.1 개요

`common/export_utils.py`는 다양한 분야의 데이터를 내보내기 위한 **공통 모듈**입니다.
인구통계뿐 아니라 다른 데이터 분석 프로젝트에서도 재사용할 수 있습니다.

### 5.2 모듈 구조

```
common/
├── __init__.py           # 모듈 초기화
└── export_utils.py       # 내보내기 유틸리티
    ├── DataExporter      # 메인 클래스
    ├── export_to_excel() # 단순 함수
    ├── export_to_markdown()
    └── export_to_html()
```

### 5.3 DataExporter 클래스

```python
from common.export_utils import DataExporter

# 인스턴스 생성
exporter = DataExporter(
    tables_data=tables_data,      # Dict[str, List[Dict]] - 시트명: 데이터
    charts_data=charts_data,      # Dict[str, str] - 시트명: base64 이미지
    sort_config=sort_config,      # Dict[str, str] - {'column': 'col', 'direction': 'asc'}
    report_title="보고서 제목",
    header_labels=header_labels   # Dict[str, str] - 컬럼명 한글 매핑
)

# 내보내기 실행
results = exporter.export_all(output_dir, filename_base)
```

### 5.4 주요 기능

| 기능 | 설명 |
|------|------|
| **정렬 지원** | `sort_config` 파라미터로 정렬 상태 전달 |
| **첫 행 고정** | 합계 행을 정렬에서 제외하고 최상단 유지 |
| **탭 형식 HTML** | 지표별 탭으로 구분된 인터랙티브 HTML |
| **차트 포함** | Base64 인코딩된 차트 이미지 HTML에 삽입 |
| **컬럼명 한글화** | `header_labels`로 영문 컬럼명을 한글로 변환 |

### 5.5 사용 예시

```python
# edu_dash2.py에서 사용 예시

# 정렬 파라미터 받기
sort_column = request.args.get('sort_column', '')
sort_direction = request.args.get('sort_direction', 'asc')
sort_config = {'column': sort_column, 'direction': sort_direction} if sort_column else None

# DataExporter로 내보내기
exporter = DataExporter(
    tables_data={
        '유소년인구': youth_data,
        '고령인구': elderly_data
    },
    charts_data={
        '유소년인구': youth_chart_base64,
        '고령인구': elderly_chart_base64
    },
    sort_config=sort_config,
    report_title="인구 집계표 보고서"
)

results = exporter.export_all(Path('output'), 'population_report')
# 결과: {'excel': True, 'markdown': True, 'html': True, 'files': [...]}
```

### 5.6 다른 프로젝트에서 사용

## 8. 문제 해결

### 8.1 자주 발생하는 문제

| 문제 | 원인 | 해결 방법 |
|------|------|----------|
| 정렬 아이콘이 두 개 표시됨 | CSS와 HTML 중복 | HTML에서 아이콘 텍스트 제거 |
| 시군구 데이터가 안 나옴 | 하위 시군구 필터 오류 | LEFT(sigungu_code, 4)로 그룹화 |
| 차트에 지역명이 없음 | 컬럼명 매핑 오류 | sigungu_nm 키 확인 |
| 내보내기 정렬이 다름 | 정렬 상태 미전달 | sort_column, sort_direction 파라미터 추가 |
