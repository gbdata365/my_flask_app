## 생성된 SQL

```sql
SELECT 
    d.sigungu_nm as 시군구,
    ROUND(SUM(
        p.male_age_0 + p.male_age_1 + p.male_age_2 + p.male_age_3 + p.male_age_4 + p.male_age_5 +
        p.female_age_0 + p.female_age_1 + p.female_age_2 + p.female_age_3 + p.female_age_4 + p.female_age_5
    )::numeric / NULLIF(SUM(p.total_pop), 0) * 100, 2) as "6세이하비율"
FROM fact_population_by_age p
JOIN dim_admin_area d ON p.admin_code = d.admin_code
WHERE p.base_ym = (SELECT MAX(base_ym) FROM fact_population_by_age)
  AND d.sido_nm = '경상북도'
  AND d.sigungu_nm IS NOT NULL
GROUP BY d.sigungu_nm
ORDER BY "6세이하비율" DESC NULLS LAST
LIMIT 10;
```
