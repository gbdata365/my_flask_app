1. 사용 테이블 목록
------------------------------------------------------------------------------

[행정구역 정보 테이블]
- dim_admin_area
  용도: 시도/시군구/읍면동 행정표준코드 및 권역 정보
  주요 컬럼:
    - sigungu_code (VARCHAR 5): 시군구 행정표준코드 5자리 (예: 11010, 52113)
    - sido_nm: 시도명 (예: 서울특별시, 전북특별자치도)
    - sigungu_nm: 시군구명 (예: 종로구, 전주시 덕진구)
    - region_nm: 권역명 (수도권, 충청권, 호남권, 영남권, 강원권, 제주권)
  참고: 2024년 전라북도 → 전북특별자치도 명칭 변경 반영됨
        띄어쓰기 포함된 하위구 (전주시 덕진구, 포항시 남구 등) 정규화

------------------------------------------------------------------------------

[기업체현황 메인 테이블]
- giup_summary
  용도: 기준시기/시도/시군구별 기업체 현황 메인 테이블 (상세 테이블과 조인용)
  주요 컬럼:
    - id (SERIAL): 고유 ID (PK)
    - base_ym (VARCHAR 6): 표준화된 기준년월 (202312, 202403 등)
    - base_ym1 (VARCHAR 30): 원본 기준시기 (2023년, 2024년 1분기)
    - data_type (VARCHAR 15): 자료유형 (annual/quarterly/monthly)
    - sido_nm (VARCHAR 30): 시도명
    - sigun_nm (VARCHAR 30): 시군구명
    - sigun_cd (VARCHAR 5): 시군구코드 (dim_admin_area 매칭 결과)
  인덱스: base_ym, sigun_cd, data_type
  UNIQUE: (base_ym, data_type, sido_nm, sigun_nm)

2. 데이터 적재 방식
------------------------------------------------------------------------------

엑셀 파일 → read_xlsx.py 실행 → PostgreSQL DB 적재

처리 과정:
1. 엑셀 병합 셀 해제 (openpyxl)
   - 병합된 셀을 해제하고 첫 번째 값으로 모든 셀 채움
   - 원본 파일 백업 (.xlsx.bak) 생성

2. dim_admin_area 테이블과 매칭
   - 시도명 + 시군구명으로 sigungu_code(5자리) 조회
   - 전북특별자치도 ↔ 전라북도 호환 처리

3. 하이브리드 테이블 구조로 DB 적재
   - giup_summary: 기준시기/지역 정보 (메인)
   - giup_detail_*: 각 분류별 상세 데이터 (FK로 연결)

4. '*' 값(3건 이하 비식별화) → 1로 변환

사용법:
  python read_xlsx.py                  # 모든 파일 처리
  python read_xlsx.py --file 파일명    # 단일 파일 처리
  python read_xlsx.py --init           # 테이블 초기화만
