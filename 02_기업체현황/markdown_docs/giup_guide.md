## 기업통계등록부란?

### 개요
**기업통계등록부(SBR, Statistical Business Register)**는 통계청에서 관리하는 전국 사업체 및 기업에 대한 기본 정보를 담고 있는 통계등록부입니다.

### 목적
- 📊 **통계 조사의 모집단 관리**: 경제총조사, 광업제조업조사 등의 기초자료
- 🔍 **사업체 현황 파악**: 업종별, 지역별, 규모별 사업체 분포 현황
- 📈 **정책 수립 지원**: 지역경제 분석, 산업정책 수립의 기초자료
- 🔗 **행정자료 연계**: 국세청, 고용보험 등 행정자료와 연계한 통합 통계

### 주요 특징
| 특징 | 설명 |
|------|------|
| **전수 조사** | 전국 모든 사업체 정보 포함 |
| **분기별 갱신** | 분기마다 최신 정보 업데이트 |
| **다차원 분석** | 조직형태, 산업, 지역, 규모 등 다양한 차원 제공 |
| **행정자료 기반** | 국세청, 고용보험 등 행정자료 활용으로 높은 정확도 |

## 데이터 구조

### 데이터베이스 테이블: `sbr_quarter_summary`

#### 1. 기준 정보
```
CRTR_YR (기준연도)     : 자료 귀속 연도 (YYYY)
QU_SE_CD (분기구분코드) : 분기 (1,2,3,4)
```

#### 2. 지역 정보
```
ADCLSF_CTPV_CD (시도코드)   : 2자리 행정구역 코드
ADCLSF_SGG_CD (시군구코드)  : 5자리 행정구역 코드
CTPV_NM (시도명)            : 시도명 (예: 서울특별시)
SGG_NM (시군구명)           : 시군구명 (예: 강남구)
```

#### 3. 조직형태별 통계 (ORG_*)
```sql
ORG_개인사업체          -- 개인 사업자
ORG_회사법인            -- 주식회사, 유한회사 등
ORG_회사이외법인        -- 재단법인, 사단법인 등
ORG_비법인단체          -- 법인격 없는 단체
ORG_국가지방자치단체    -- 정부기관, 지방자치단체
ORG_합계                -- 총 사업체수
```

**활용 예시**:
- 개인사업체 vs 법인 비율 분석
- 지역별 법인 사업체 밀집도 파악

#### 4. 성별 통계 (GENDER_*)
```sql
GENDER_남자             -- 남성 대표자
GENDER_여자             -- 여성 대표자
GENDER_(공백)           -- 성별 미상
GENDER_합계             -- 전체
```

**활용 예시**:
- 여성 대표자 비율 추이 분석
- 산업별 성별 분포 비교

#### 5. 영업상태별 통계 (STATUS_*) 
```sql
STATUS_영업중           -- 현재 영업 중인 사업체
STATUS_폐업             -- 폐업한 사업체
STATUS_합계             -- 전체
```

**활용 예시**:
- 지역별 폐업률 분석
- 산업별 생존율 파악

#### 6. 산업분류별 통계 (IND_*)
한국표준산업분류(KSIC) 대분류 기준
```sql
IND_농업,임업,어업      -- A: 1차 산업
IND_광업                -- B
IND_제조업              -- C: 2차 산업
IND_전기가스공급업      -- D
IND_수도하수폐기물      -- E
IND_건설업              -- F
IND_도매및소매업        -- G: 3차 산업
IND_운수및창고업        -- H
IND_숙박및음식점업      -- I
IND_정보통신업          -- J
IND_금융및보험업        -- K
IND_부동산업            -- L
IND_전문과학기술서비스  -- M
IND_사업시설관리        -- N
IND_공공행정            -- O
IND_교육서비스업        -- P
IND_보건사회복지        -- Q
IND_예술스포츠여가      -- R
IND_협회및개인서비스    -- S
IND_가구내고용활동      -- T
IND_국제외국기관        -- U
IND_(공백)              -- 미분류
IND_합계                -- 전체
```

**활용 예시**:
- 제조업 vs 서비스업 비중 분석
- 지역별 산업 특화도 분석
- 신성장 산업(정보통신, 전문과학기술) 추이

#### 7. 수치형 통계 (STATS_*)

##### 종사자수
```sql
STATS_기업종사자수_건수     -- 종사자 정보가 있는 기업 수
STATS_기업종사자수_합계     -- 전체 종사자수
STATS_기업종사자수_평균     -- 기업당 평균 종사자수
STATS_기업종사자수_공백건수 -- 종사자 정보 없는 기업 수
```

##### 매출금액 (단위: 백만원)
```sql

STATS_기업매출금액_공백건수 -- 매출 정보 없는 기업 수
```

##### 상용근로자수

##### 임시일용근로자수
```sql

STATS_기업임시일용근로자수_합계
STATS_기업임시일용근로자수_평균
```

## 주요 통계 지표

### 1. 사업체 밀도
```
사업체 밀도 = 총 사업체수 / 인구 수
```
지역 경제 활성화 정도를 나타내는 지표

### 2. 평균 종사자수
```
평균 종사자수 = 총 종사자수 / 총 사업체수
```
사업체 규모를 나타내는 지표

### 3. 여성 대표자 비율
```
여성 대표자 비율 = (여성 대표 사업체수 / 전체 사업체수) × 100
```
성평등 지표

### 4. 폐업률
```
폐업률 = (폐업 사업체수 / 전체 사업체수) × 100
```
사업 환경 안정성 지표

### 5. 산업 다양성 지수
허핀달-허쉬만 지수(HHI) 활용
```
HHI = Σ (산업별 비중)²
```
값이 낮을수록 산업이 다양함

### 6. 1인당 매출액
```
1인당 매출액 = 총 매출액 / 총 종사자수
```
생산성 지표

## 데이터 활용 방법

### SQL 쿼리 예시

#### 1. 시도별 사업체 현황
```sql
SELECT
    "CTPV_NM" as 시도명,
    SUM("ORG_합계") as 총사업체수,
    SUM("STATS_기업종사자수_합계") as 총종사자수,
    ROUND(SUM("STATS_기업종사자수_합계")::numeric / NULLIF(SUM("ORG_합계")::numeric, 0), 2) as 평균종사자수
FROM sbr_quarter_summary
WHERE "CRTR_YR" = '2024' AND "QU_SE_CD" = '4'
GROUP BY "CTPV_NM"
ORDER BY 총사업체수 DESC;
```

#### 2. 시계열 분석 (분기별 증감)
```sql
SELECT
    "CRTR_YR" || 'Q' || "QU_SE_CD" as 분기,
    SUM("ORG_합계") as 총사업체수,
    LAG(SUM("ORG_합계")) OVER (ORDER BY "CRTR_YR", "QU_SE_CD") as 전분기,
    SUM("ORG_합계") - LAG(SUM("ORG_합계")) OVER (ORDER BY "CRTR_YR", "QU_SE_CD") as 증감
FROM sbr_quarter_summary
GROUP BY "CRTR_YR", "QU_SE_CD"
ORDER BY "CRTR_YR", "QU_SE_CD";
```

#### 3. 산업별 여성 대표자 비율
```sql
SELECT
    CASE
        WHEN "IND_제조업" > 0 THEN '제조업'
        WHEN "IND_건설업" > 0 THEN '건설업'
        WHEN "IND_도매및소매업" > 0 THEN '도소매업'
        ELSE '기타'
    END as 주력산업,
    SUM("GENDER_여자") as 여성대표,
    SUM("GENDER_합계") as 전체,
    ROUND(SUM("GENDER_여자")::numeric / NULLIF(SUM("GENDER_합계")::numeric, 0) * 100, 2) as 여성비율
FROM sbr_quarter_summary
WHERE "CRTR_YR" = '2024' AND "QU_SE_CD" = '4'
GROUP BY 주력산업;
```

#### 4. 상위 성장 지역 (YoY)
```sql
WITH current_year AS (
    SELECT "SGG_NM", SUM("ORG_합계") as cnt_2024
    FROM sbr_quarter_summary
    WHERE "CRTR_YR" = '2024' AND "QU_SE_CD" = '4'
    GROUP BY "SGG_NM"
),
previous_year AS (
    SELECT "SGG_NM", SUM("ORG_합계") as cnt_2023
    FROM sbr_quarter_summary
    WHERE "CRTR_YR" = '2023' AND "QU_SE_CD" = '4'
    GROUP BY "SGG_NM"
)
SELECT
    c."SGG_NM" as 지역,
    c.cnt_2024 as "2024년",
    p.cnt_2023 as "2023년",
    ROUND((c.cnt_2024 - p.cnt_2023)::numeric / p.cnt_2023 * 100, 2) as 증가율
FROM current_year c
JOIN previous_year p ON c."SGG_NM" = p."SGG_NM"
ORDER BY 증가율 DESC
LIMIT 10;
```

### Python 분석 예시

#### Pandas를 활용한 데이터 분석
```python
import pandas as pd
from module.db import get_db_connection

# 데이터 로드
conn = get_db_connection()
query = """
    SELECT * FROM sbr_quarter_summary
    WHERE "CRTR_YR" = '2024'
"""
df = pd.read_sql(query, conn)

# 1. 기초 통계
print(df.describe())

# 2. 시도별 집계
sido_stats = df.groupby('CTPV_NM').agg({
    'ORG_합계': 'sum',
    'STATS_기업종사자수_합계': 'sum',
    'STATS_기업매출금액_합계': 'sum'
```

## FAQ

### Q1. 데이터 갱신 주기는?
**A**: 분기별로 갱신됩니다. 각 분기 종료 후 약 2-3개월 후 데이터가 공개됩니다.

### Q2. 사업체수와 기업체수의 차이는?
**A**:
- **사업체**: 물리적 사업장 단위 (예: 본점, 지점 각각 1개)
- **기업체**: 법적 경영 단위 (예: 본점+지점 = 1개 기업)

### Q3. 공백(NULL) 값의 의미는?
**A**:
- **통계적 비밀보호**: 특정 항목이 3개 미만인 경우 '*'로 표시 → NULL 처리
- **정보 미제공**: 해당 항목에 대한 정보가 없는 경우

### Q4. 매출금액이 0인 경우는?
**A**:
- 신규 개업으로 아직 매출이 발생하지 않은 경우
- 국세청 자료 연계 전 상태
- 비영리 단체 등 매출이 없는 경우

### Q5. 폐업 사업체도 포함되나요?
**A**: 네, 폐업 사업체도 포함됩니다. `STATUS_폐업` 컬럼으로 구분 가능합니다.

### Q6. 지역 코드가 매핑되지 않은 경우는?
**A**:
- 시군구명 표기가 불일치한 경우 (예: "창원시 성산구" vs "창원시 성산면")
- 행정구역 개편으로 코드가 변경된 경우
- 해당 경우 수동으로 매핑 필요

### Q7. 데이터를 다운로드할 수 있나요?
**A**: CSV 형식으로 내보내기 가능합니다.
```bash
python read_xlsx_new.py --file "data/파일명.xlsx" --output output.csv
```

### Q8. 대시보드는 어떻게 사용하나요?
**A**: Flask 애플리케이션을 실행한 후 다음 URL로 접속하세요:
- **전체 개요**: `/02_기업체현황/routes/대시보드1`
- **산업 분석**: `/02_기업체현황/routes/대시보드2`
- **지역 분석**: `/02_기업체현황/routes/대시보드3`

또는 상단 메뉴에서 "대시보드1", "대시보드2", "대시보드3"을 클릭하세요.
