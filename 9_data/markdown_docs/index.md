# 데이터베이스 뷰어

PostgreSQL 데이터베이스를 웹에서 조회할 수 있는 도구입니다.

## 주요 기능

1. **데이터베이스 목록 조회**: 서버에 있는 모든 데이터베이스 목록을 확인
2. **테이블 목록 조회**: 선택한 데이터베이스의 테이블 목록과 컬럼 수 표시
3. **테이블 데이터 조회**: 테이블의 데이터를 페이지 단위로 조회

## 사용 방법

1. 상단 우측의 **db viewer** 링크를 클릭합니다.
2. 데이터베이스 목록에서 원하는 데이터베이스를 선택합니다.
3. 테이블 목록에서 조회할 테이블을 선택합니다.
4. 테이블 데이터가 하단에 표시됩니다.

## 테이블 구조

현재 사용 중인 주요 테이블:

| 테이블명 | 설명 |
|----------|------|
| `cache_sigungu_indicators` | 시군구별 인구/세대 지표 캐시 테이블 |
| `cache_sigungu_age` | 시군구별 연령별 1인가구 캐시 테이블 |
| `dim_admin_area` | 행정구역 마스터 테이블 (권역/시도/시군구) |
| `code_indicator` | 지표 정의 코드 테이블 |
| `code_age_group` | 연령 그룹 정의 코드 테이블 |
